
# MY Diners Smart Order Fulfilment System

BFB 321 - Group 11

## Project Description

This project is a simple order management system
for MY Diners restaurant.

The system aims to improve order tracking and
kitchen station allocation.

## Step 1: Website

The website was created using HTML and CSS.

It includes:
- Customer order form
- Kitchen orders table
- Manager dashboard
- MY Diners logo

## Step 2: Python Model

The Python program can:
- Add customer orders
- Assign food items to kitchen stations
- Update order statuses
- Count orders by status

## Project Files

index.html - Website structure

style.css - Website styling

logo.png - Restaurant logo

order_model.py - Python order calculations

test_model.py - Python unit tests

README.md - Project information

## How to Run

1. Open index.html in Chrome.
2. Open order_model.py in VS Code.
3. Run the Python file.
4. Run test_model.py to check the functions.

## Current Limitations

The website currently displays sample orders.

The Python model runs separately from the website.

The Add Order button does not yet save orders.
